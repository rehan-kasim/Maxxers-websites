Frequently Asked Questions

Everything you need to know about the Newton calculation engine.

How is LTV calculated in this model?

Lifetime Value (LTV) is computed using the standard SaaS formula: ARPU divided by the Monthly Churn Rate, multiplied by your gross margin tier coefficient.

Are my calculations stored anywhere?

No. All simulations occur entirely within your browser's JavaScript execution runtime. We store zero financial data.

Can I embed this calculator on my own site?

Newton is currently designed as a standalone web utility. Stay tuned for developer widget embeds coming later this year.
